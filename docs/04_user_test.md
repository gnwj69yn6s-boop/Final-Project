# 사용자 테스트

## 1. 개요
- 기간: [날짜] ~ [날짜]
- 대상: 요리하는 성인 [N]명 (목표 10명, 최소 5명) / 모집 경로: [지인, 커뮤니티 등]
- 환경: 본인 스마트폰 또는 PC 브라우저, 배포 URL 접속
- 동의: 서비스 내 개인정보 동의 + 테스트 참여 구두 동의

## 2. 테스트 시나리오 (과제)
| # | 과제 | 성공 기준 |
|---|------|-----------|
| T1 | 가입 후 냉장고 사진 업로드, 재료 확인 | 재료 목록 생성 |
| T2 | "알레르기가 있다"고 말하고 레시피 추천받기 | 해당 재료 제외 |
| T3 | 20분 이내 레시피 요청 | 시간 조건 충족 |
| T4 | 부족한 재료를 장보기 목록에 추가 요청 | 목록 조회 확인 |
| T5 | 다음 날 재접속 후 '내 기억 보기' 확인 | 이전 정보 유지 |

## 3. 설문 (5점 척도, 1=전혀 아니다 ~ 5=매우 그렇다)
1. 재료 인식 결과가 정확했다
2. 추천 레시피가 내 상황(재료, 시간, 취향)에 맞았다
3. 내 정보를 기억하는 점이 유용했다
4. 사용 방법이 쉬웠다
5. 응답 속도가 적절했다
6. 이 서비스를 다시 사용하고 싶다
7. (주관식) 가장 불편했던 점 / 가장 좋았던 점 / 추가되면 좋을 기능
